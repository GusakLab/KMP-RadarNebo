# MissionControl-Nebo privacy policy

Effective 1 November 2026.

MissionControl-Nebo shows the health report of a RadarNebo server. It requests that report (`/health`) from the
server address set in the app, which by default is https://radar-nebo.worxbend.com.

- The app collects no personal data, has no accounts, no analytics, no advertising and no third-party SDKs.
- The only data it stores is the server address you enter, kept on your device and removed when you uninstall the app.
- Like any web request, the server you watch sees your IP address and the app's name and version (User-Agent).
  That server's own operator is responsible for its logs.
