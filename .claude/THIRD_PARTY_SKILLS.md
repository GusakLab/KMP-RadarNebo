## Refresh

From the repository root, with dot-agents checked out at `~/Projects/Github/dot-agents`:

```sh
DA=~/Projects/Github/dot-agents
for s in $(ls .claude/skills); do
  src=$(python3 -c "import json,sys; print(next(x['path'] for x in json.load(open('$DA/catalog.json'))['skills'] if x['name']=='$s'))")
  rsync -a --delete --exclude __pycache__ --exclude '*.pyc' "$DA/$src/" ".claude/skills/$s/"
done
```

Then update the hashes and snapshot line above, and review the diff before committing.
