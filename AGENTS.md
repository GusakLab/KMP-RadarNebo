# Agent Instructions

The agent instructions for this repository are in [CLAUDE.md](CLAUDE.md). They bind every agent, not only Claude.
Read CLAUDE.md, then [CODE_STYLE.md](CODE_STYLE.md) and [CONTRIBUTING.md](CONTRIBUTING.md), before you change anything.

Project skills are in `.claude/skills/<name>/SKILL.md`. When CLAUDE.md routes a task to a skill and your agent does
not load skills by itself, read that `SKILL.md` and follow it.
